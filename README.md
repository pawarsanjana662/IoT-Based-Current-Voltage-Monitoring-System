# IoT-Based Current and Voltage Monitoring System

## About the Project
This is a B.Tech final-year project developed to monitor three-phase voltage and current using a microcontroller-based system.

The system uses a PIC18F4520 microcontroller and ACS712 current sensors to monitor electrical parameters and detect abnormal conditions such as overvoltage, undervoltage, and overcurrent.

## Hardware Used
- PIC18F4520 Microcontroller
- ACS712 20A Current Sensors
- 16x2 LCD Display
- Voltage sensing circuits
- UART communication (9600 baud)

## Main Features
- Three-phase voltage monitoring
- Three-phase current monitoring
- Overvoltage and undervoltage detection
- Overcurrent detection
- LCD status display
- UART fault indication

## Programming Language
- Embedded C
